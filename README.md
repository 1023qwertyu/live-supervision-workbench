# 直播监督工作台

把之前分散在 Word、Excel、Python 里的五块东西装进一个本地网页界面，边干活边查、边打分边留痕。

## 一、包含哪五块

| 模块 | 页面 | 原来是什么 | 现在能干什么 |
|---|---|---|---|
| 01 监督体系 | `system.html` | 《抖音直播监督体系》Word（11-04） | 全文可读 + 页内搜索 + 章节目录，制度条款随手查 |
| 02 状态评分 | `scoring.html` | 《直播人员状态评分与扣分表 v1.1》Excel（11-06） | 网页填数即出 CR / VAR、逐项扣分、得分定级，台账存本机可导 CSV |
| 03 合规手册 | `manual.html` | 《电商直播合规手册·直播人员版》Word（11-06） | 十章全文 + 红线 / 禁用词可搜 |
| 04 开播核对卡 | `check.html` | 《开播前30秒核对卡》+ 个人手册附录五/六 | 50 项清单可勾选、显示完成度、按日自动重置 |
| 05 团购版手册 | `tuangou.html` | 《直播人员个人手册·团购版 V2.1》Word（11-07） | 十一章 + 六附录全文检索 |
| 06 实时监看 | `live.html` | LiveVision 监看链路 + 半小时简报自动化（11-09） | 读 `latest.json` 显示各房间得分/等级/CR/VAR 与最近简报原文 |

外加：首页 `index.html` 有**全库搜索**（三份文档 140 个小节一次搜完）和实时概览。

## 二、怎么跑

```bash
cd C:/Users/24526/WorkBuddy/监督
python serve.py
```

浏览器打开 `http://127.0.0.1:8787`（启动时会自动尝试打开）。

> 直接双击 `index.html` 也能看文档和打分，但**实时监看会读不到数据**——浏览器的 file:// 协议不允许读取本地 JSON，必须走本地服务。

参数：

| 参数 | 作用 |

| `--port 9000` | 换端口 |
| `--no-browser` | 不自动开浏览器 |
| 环境变量 `LIVEVISION_DIR` | LiveVision 根目录，默认 `D:/LiveVision` |

## 三、评分口径（与 Excel 完全一致，改动只需改一处）

规则表在 `assets/scoring.js` 顶部的 `RULES`，改这里即全局生效：

| 扣分项 | 粒度 | 单位扣分 | 单场上限 |
|---|---|---|---|
| 出镜率不达标 | 每 5 个百分点 | 3 | 25 |
| 语音活跃率不达标 | 每 5 个百分点 | 2.5 | 20 |
| 离岗 | 每满 60 秒 | 2 | 20 |
| 玩手机 | 每次 | 3 | 15 |
| 趴桌 | 每次 | 10 | 30 |
| 静音超时 | 每满 5 分钟 | 2 | 10 |
| 进食等无关行为 | 每次 | 2 | 8 |

等级：A ≥ 90，B 80–89，C 70–79，D < 70。

**硬门槛**（分数再高也压级）：
- 语音活跃率 < 80% → 最高 C
- 语音活跃率 < 70% → 直接 D
- 出镜率 < 50% → 直接 D
- 代播 / 播放录播 → 不计分，直接 D 并转人工核查

自测：填入示例数据（有效直播 7200 秒、出镜 6480 秒、语音 3960 秒、离岗 300 秒、玩手机 2 次、静音 12 分钟）应得 **67.5 分 / D 级**，扣分明细 0 + 12.5 + 10 + 6 + 0 + 4 + 0 = 32.5。

## 五、更新文档的正确方式

Word 改完后，把新的 HTML 覆盖 `src/system.html`（或 `manual.html` / `tuangou.html`），然后：

```bash
python build.py
```

页面和检索索引会一起重建，不用手改 HTML。

## 七、这套东西的边界

- **能当处罚依据**：离岗、趴桌、静音超时、出镜率、语音活跃率（叠声纹）。
- **只能当线索**：玩手机（COCO 模型漏检严重）、专注率/走神（公开研究 F1 仅 0.25–0.48）。
- **必须人工核**：代播、播放录播——系统只给「待核」，不给结论。
- **不可改的口径**：语音活跃率 80% 封顶 C、70% 判 D。

## 八、已知限制

1. 检索是「按小节切片 + 字符串匹配」，不做分词和同义词，搜「核销」能中、搜「核销流程」中不了。
2. 台账存在浏览器里，多人不能共享；要多人协作得接后端。
3. 实时监看依赖 `latest.json`；超过 40 分钟没更新会在页面顶部提示「数据已过期」，不会用旧数据冒充实时。
4. 页面按 1440 宽设计，窄屏会收起侧栏与目录（正文仍可读）。
