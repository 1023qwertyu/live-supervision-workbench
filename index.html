怎么启动

双击 index.html 也能看文档，但实时数据要跑本地服务。

在工作台目录执行：

python serve.py

然后浏览器打开 http://127.0.0.1:8787。默认会尝试自动打开浏览器。

数据来源：D:\LiveVision\output\periodic\。换机器或换路径时设环境变量 LIVEVISION_DIR 即可。

这套东西的边界

写清楚才不会用错。

  • 能当处罚依据的：离岗、趴桌、静音超时、出镜率、语音活跃率（叠声纹）。
  • 只能当线索的：玩手机（漏检严重）、专注率/走神（F1 仅 0.25–0.48，不参与评分）。
  • 必须人工核的：代播、播放录播——系统只给「待核」，不给结论。
  • 口径唯一的：语音活跃率 < 80% 封顶 C，< 70% 直接 D；这条不改。
